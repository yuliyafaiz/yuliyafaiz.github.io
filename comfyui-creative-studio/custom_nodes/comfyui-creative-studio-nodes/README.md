# ComfyUI Creative Studio Nodes

Seven nodes for reference-driven production in ComfyUI: Reference Collector, Product/Character Profile Loader, Prompt Template, Generation Metadata Saver (PNG + sidecar JSON + model SHA-256), Batch Variant Manager and Project Metadata. Usable on their own or with the Creative Studio app.

Install: copy or symlink this folder into `ComfyUI/custom_nodes/` and restart ComfyUI. No extra dependencies.

Documentation: [docs/CUSTOM_NODES.md](../../docs/CUSTOM_NODES.md). Tests: `python -m pytest tests`.
